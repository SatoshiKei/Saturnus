Como jogar
----------
1. Abrir henrique_rtp_capture na Bancada → Packets.
2. Perceber dois SSRC recorrentes.
3. Filter SSRC A → Select visible → Create Stream From Selection.
4. Reconstruct Audio → conversa técnica inteligível (prova o método).
5. Filter SSRC B → Create Stream → Reconstruct (ordem de captura) → voz quebrada.
6. Sort by Sequence → Reconstruct de novo → conversa anômala inteligível.
7. Finding técnico registrado; achievement CASSINI-HUYGENS.
