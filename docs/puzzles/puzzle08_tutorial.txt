-------------------------------
1. Selecionar ~1 ciclo na timeline (tolerância ~4.2–7.5 s).
2. Find Similar Regions → ~8 regiões (marcadores sem rótulo de anomalia).
3. Stack / Overlay → residual energy por região (jogador observa o outlier).
4. Build Common Pattern → média dos ciclos normais (excluir o anômalo).
5. Difference / Subtract Reference → alvo = ciclo anômalo.
